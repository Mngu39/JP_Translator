JP_Translator GitHub patch v8

이 ZIP은 저장소 루트 기준 패치입니다.
public 폴더만 올리는 것이 아니라 .github 와 tools도 같이 올려야 합니다.

1) ZIP을 풉니다.
2) JP_Translator GitHub 저장소 루트에 아래를 그대로 덮어씁니다.
   - public/
   - tools/
   - .github/workflows/update-jmdict.yml
3) Commit / Push 합니다.
4) Pages 배포가 끝난 뒤 사이트를 새로 엽니다.
5) JMdict/KANJIDIC 데이터는 최초 1회 다음 작업을 실행해야 합니다.
   GitHub 저장소 > Actions > Update JMdict data > Run workflow
   완료되면 public/text/jmdict_usage.min.json이 자동으로 갱신/커밋됩니다.
   이후에는 단어장 페이지 하단의 '업데이트' 링크로 같은 Actions 화면을 열 수 있습니다.

주의:
- 텍스트 번역기→단어장 연결 기능은 이번 패치에 포함하지 않았습니다.
- 과거 저장 데이터를 위한 별도 backfill/migration 코드는 넣지 않았습니다.
